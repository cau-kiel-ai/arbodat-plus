ArboDat+ REST API

All endpoints are served under /api/ by the ArboDat+ Web API:
  local installation:   http://localhost:<port>>/api/...
  server installation:  https://<your-server>/api/...

--------------------- Export ---------------------
## Export all data
/api/data_export?export_file_name=<name>

## Filter by research projects
/api/data_export?research_projects=<id1>,<id2>,...&export_file_name=<name>

## Filter by sites
/api/data_export?sites=<id1>,<id2>,...&export_file_name=<name>

## Filter by features
/api/data_export?features=<id1>,<id2>,...&export_file_name=<name>

## Filter by samples
/api/data_export?samples=<id1>,<id2>,...&export_file_name=<name>
