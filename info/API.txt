ArboDat+ REST API

All endpoints are served under /api/ by the ArboDat+ web server:
  local installation (desktop app):  http://localhost:8480/api/...
  server installation:               https://<your-server>/api/...
The list below uses the local default address.

--------------------- Export ---------------------
## Export all data
localhost:8480/api/data_export?export_file_name=<name>

## Filter by research projects
localhost:8480/api/data_export?research_projects=<id1>,<id2>,...&export_file_name=<name>

## Filter by sites
localhost:8480/api/data_export?sites=<id1>,<id2>,...&export_file_name=<name>

## Filter by features
localhost:8480/api/data_export?features=<id1>,<id2>,...&export_file_name=<name>

## Filter by samples
localhost:8480/api/data_export?samples=<id1>,<id2>,...&export_file_name=<name>
