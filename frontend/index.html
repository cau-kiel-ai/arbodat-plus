Welcome to ArboDat+

ArboDat+ is the new implementation of the archaeobotanical database program ArboDat. It is designed to simplify and enhance your data management experience. ArboDat+ incorporates both new and existing features. More details about What's new can also be found on Zenodo.

Key changes and what they allow you to do:

  • ArboDat+ is designed as an operating system independent web application, which can be run in almost any modern browser on most computers.
  • A newly implemented PostgreSQL database transitions the system to an open and free platform. The database remains relational, however by translating the old database schema according to the third normal form, data integrity is ensured.
  • ArboDat+ uses central lists of standardized vocabularies and thesauri, stored at Dante VZG. It is also possible to add local attribute labels to the central Dante Server. These will be manually reviewed prior to being uploaded centrally - updating lists for all users automatically. This way, the data becomes consistent and interoperable with other data sets using the same data lists, while still allowing flexibility for unique needs.
  • Migration of existing data sets is possible via the 'Data Migration' module.
  • The data entry structure has largely remained the same as in the previous version. New records can be entered through the ‘Data Input’ module.
  • Data entries can be queried, filtered, altered and exported into different file types for download via the 'Data Explorer' module.
  • In addition, ArboDat+ provides an interactive map for easy location management of sites and samples.



This continued development of ArboDat is being carried out as a collaborative project between NFDI for Objects (NFDI4O), Kiel University (CAU), and the Lower Saxony Institute for Historical Coastal Research (NIhK).
