        List of site and sample coordinates for the selected sites.
        - To create coordinates select 'dante coordinateSystem'.
        - If a coordinate system you are looking for is not in the central thesauri list (dropdown), you can use the ‘Add to JSON’ option to save the 'coordinateSystem' at the bottom of the page.
        - Before using the ‘Add to JSON’ option, please fill in all applicable fields(lon, lat, alt, lon WGS84, lat WGS84, remarks).
        - The 'altitude' and 'z coordinate' from the former database are displayed. But the new database only uses the altitude value.
        - The longitude and latitude WGS 84 fields are computed and filled in automatically (except for the coordinate systems 'DHDN / 3-degree Gauss' and 'local').
        - If ‘local’ is selected as coordinate system, this can be described in the ‘remarks’ text field.
        - To select coordinate systems or create coordinates in several rows simultaneously select multiple rows.
        - To select or deselect a row use the checkbox on the left. To select or deselect all rows use the checkbox at the top left of a table.
